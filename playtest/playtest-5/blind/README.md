# Playtest 5: listen blind

Each sound is here twice, as `A` and `B`: one is the preset as it was,
the other is the playtest agent's version. Which is which changes from
sound to sound. Listen to each pair and write which you prefer, and why
in a few words, before you open `KEY.md`.

| Sound | The words the agent worked towards |
|---|---|
| jump | "a light, springy jump in a cartoon platform game" |
| footstep | "a single footstep on a hard floor" |
| missile | "a missile launching with a whoosh" |
